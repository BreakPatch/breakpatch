The second beta of Breakpatch Community: free and open source (Apache 2.0), for one person on one Mac.

## Update or install

If you have the first beta, Breakpatch updates itself: Settings → About → **Check for updates**, then **Restart to update**. Your tests stay as they are.

To install it, open Terminal and paste:

```sh
curl -fsSL https://breakpatch.dev/install | sh
```

## What's new

- **Phones and tablets.** Pick one under **Screen size** in **New test**: iPhone 15, iPhone SE, Pixel 8, Galaxy S24, iPad, iPad Pro 11 or Galaxy Tab S9. Your site gets the device's screen size and a touch screen, and your clicks become taps. Tap, double tap, long press, swipe, scroll and drag and drop are all there. It's still Breakpatch's own browser, Chromium, at the device's size: not Safari.
- **Call your API.** A **Call** step calls your app's API in the middle of a test, for example to mark an order as paid, turn on a feature flag or get a one-time code from a test API. It can keep a value from the reply, and a later **Write text** step types it. **Try it** makes the call once.
- **Import from Playwright or Cypress.** **Import…**, next to **New test**, reads a Playwright or Cypress test (it never runs it), turns its steps into Breakpatch steps and lists what it left out, with why. Then Breakpatch learns the screens by doing each step once.
- **Retries.** When a test in a suite fails because the page was slow, the suite runs it again from the start, in a new browser. Once, unless you change it in the suite: **Don't retry**, **Retry once** or **Retry twice**. **Run all** retries once too. Every retry shows, as *Passed on retry 1* in the suite run and the report, and in a JUnit export.
- **Flaky tests.** A test whose last run passed only on a retry is marked **Flaky** in the Tests tab and in its report, with why. Mark it as known flaky, or say it isn't. A step whose screen check only just passed says *Passed, but only just*.
- **Links to a test.** **Copy link** in a test's or a suite's **⋯** menu copies a `breakpatch://` link to paste in a pull request or an issue. Clicking it opens that test or suite in the right tests folder, on any Mac that has opened the folder in Breakpatch.
- **Several tests folders.** Every tests folder you open stays in the switcher at the top of Apps and Suites: click to go back to one, or press ⌘1 to ⌘9. A saved secret can be kept for some folders only (Settings → Saved secrets → **Where it may be used**).

The [documentation](https://breakpatch.dev/docs/) has a section on each.

Team and Business are coming later; their pricing isn't decided yet.

## Your tests folder and older versions

A tests folder stays as it is until you use something new in it. Then it moves to a newer format, which the first beta can't open:

- your first phone or tablet test (or an app whose default screen size is a phone or tablet) moves it to format 2,
- your first Call step moves it to format 3.

The format is `schemaVersion` in the folder's `breakpatch.json`. The first beta says "This folder was saved by a newer Breakpatch. Update to open it." A folder never moves back to an older format, even if you delete those tests. So if the folder is shared, for example through Git, update Breakpatch on every Mac that uses it first.

## What you need

- A Mac with Apple Silicon (M1 or later). Intel Macs aren't supported.
- macOS 14 Sonoma or later.
- 16 GB of memory or more.
- About 3 GB of disk space for the AI assistant, plus the test browser.

## It's a beta

Breakpatch works, but expect some rough edges. New betas arrive by themselves through the app's updates (Settings → About → **Check for updates**), and your tests stay as they are.
