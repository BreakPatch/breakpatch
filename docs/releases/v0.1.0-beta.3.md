The third beta of Breakpatch Community: free and open source (Apache 2.0), for one person on one Mac.

## Update or install

If you have an earlier beta, press Settings → About → **Check for updates** once, then **Restart to update**. Earlier betas look for updates only when you press it; from this beta on, Breakpatch also checks by itself. Your tests stay as they are.

To install it, open Terminal and paste:

```sh
curl -fsSL https://breakpatch.dev/install | sh
```

## What's new

- **Updates by themselves.** Breakpatch looks for a new version about 10 seconds after it opens, and every hour while it's open. A new version downloads in the background, then a banner says it's ready: press **Restart to update** when it suits you. The check waits while you record or run a test, and while setup downloads the test browser or the AI assistant. If Breakpatch can't reach GitHub, it says nothing and tries again an hour later. Settings → About shows when it last checked.
- **Check for updates doesn't hang.** When GitHub doesn't answer, it stops within a minute and says so, and Breakpatch tries again within the hour.
- **Warnings in the PDF.** A test that passed, but has a step whose check covers nothing, now lists its steps in the PDF, with that step open. Before, it printed as "10 steps, all passed", and the warning "This step's check covers nothing. Re-record it." was left out.
- **Downloads that take a while.** A **Check download** step now waits for a file that started in time to finish, for up to 2 minutes more. A big file or a slow server no longer fails it with "No file was downloaded". If the file doesn't finish, the step says so.
- **Imported tests on a slow Mac.** When Breakpatch learns an imported test's screens, its first step no longer stops with "The page changed before your click reached it" when nothing had changed. It now waits a moment for the browser's first picture.
- **The install command on macOS's own sh.** It no longer stops at its first message. macOS's sh read part of the "…" in it as a name.
- **Test details in the recorder.** The focus ring round the test's name is no longer cut off, and a screen reader says "Test details" once, not twice.

The [documentation](https://breakpatch.dev/docs/#updates) says more about updates.

Team and Business are coming later; their pricing isn't decided yet. The Linux desktop app is coming later too.

## What you need

- A Mac with Apple Silicon (M1 or later). Intel Macs aren't supported.
- macOS 14 Sonoma or later.
- 16 GB of memory or more.
- About 3 GB of disk space for the AI assistant, plus the test browser.

## It's a beta

Breakpatch works, but expect some rough edges. New betas arrive by themselves: Breakpatch checks for updates when it opens and every hour, and your tests stay as they are.
