# Security

## Reporting a problem

Please don't open a public issue for a security problem. Email
**[support@breakpatch.dev](mailto:support@breakpatch.dev)** with "Security" in the subject, and
include:

- what you found and where (the app, the engine, the install command, the website),
- the steps to reproduce it, and the Breakpatch version (Settings → About),
- what an attacker could do with it.

Leave out real customer data, tokens and passwords. We'll reply to say we have it, keep you told
as we fix it, and credit you in the release notes if you'd like.

## Supported versions

The latest release. Breakpatch updates itself, and running the install command again updates it
too, so fixes ship as a new release.

## Scope

This repository, the Community edition: the desktop app, the engine sidecar, the install command
(`https://breakpatch.dev/install`) and the release files on GitHub Releases. Problems in
Breakpatch Team or the licence service can go to the same address.
